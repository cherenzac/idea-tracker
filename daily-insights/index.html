November 21 worked example: order and moving averages

Worked example: same data, different order

Start at c = 0. For each observation x, update c to (c + x) / 2. Move the value 12 through three zeros. Evaluate each final estimate on the same four observations:

  • 12 first: final estimate 0.75, mean squared error 32.0625.
  • 12 second: final estimate 1.5, mean squared error 29.25.
  • 12 third: final estimate 3, mean squared error 27.
  • 12 last: final estimate 6, mean squared error 36.

The arithmetic mean is 3 in all four orders. On this fixed sample, mean squared error at any estimate c is 27 + (c − 3)². That explains the batch baseline without assuming it will generalize to a changing stream.

This is a one-centroid, fixed-step illustration with no reassignment. It is not an implementation or benchmark of e-means, which uses a different update and discusses centroid finalization.
